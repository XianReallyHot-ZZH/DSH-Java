DSH-Java 骨架已启动（L01）

七模块 Maven 骨架与最小启动就位，依赖方向由 ArchUnit 守护：

  • app — Spring Boot 启动器（扫描入口，非装配中心）
  • trigger — HTTP 控制器 / api 实现方 / SSE 流服务
  • api — 对外契约（I*Api / DTO / Response 信封）
  • case — 用例编排（策略树）
  • domain — 领域核心（纯 Java，依赖圆心）
  • types — 插件开发契约包
  • infrastructure — 端口适配 + DAO + 组合根

对话控制台随 L05 上线；本页为占位页。
